## Pourquoi elle n'est pas dans ce dossier

GitHub refuse les fichiers de plus de 25 Mo dans un dossier du dépôt. La version d'origine est donc publiée dans la section « Releases », prévue pour les gros fichiers.

Le fichier `videon8n-leger.mp4`, dans ce dossier, est une version allégée de 20 Mo (image réduite à 640 × 374 pixels) qui se lit directement sur GitHub.
